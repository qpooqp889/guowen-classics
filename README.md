# 古文小冊｜國中國文古文學習頁

「古文小冊」是一個以國中程度為優先的文言文互動學習網站。網站以「紙上山水・數位課本」為視覺方向，將原文、白話語譯、特殊字音、朗讀與學習紀錄整合在同一個閱讀流程中，讓學生可以從篇章閱讀開始，逐步建立文言文理解能力。

## 主要功能

| 功能 | 說明 |
| --- | --- |
| 百篇文白資料庫 | 收錄 100 篇篇目，提供篇名、作者、朝代、文類、分類與來源欄位。 |
| 文白對照 | 原文與重新整理的白話語譯以段落對照呈現，移入原文段落時會同步高亮語譯。 |
| 特殊字音批註 | 段落中可查看注音、異讀、通假字與字義提示，也能點擊朗讀。 |
| 朗讀學習 | 支援單段、字詞與整篇連續朗讀，並可選擇 100%、125%、150% 字級。 |
| 收藏與複習 | 可將篇章加入「我的收藏」，並使用字音／解釋測驗、歷史紀錄與錯題本。 |
| 學習進度 | 以閱讀完成度、測驗紀錄與錯題狀態協助學生掌握學習進度。 |
| 作者脈絡 | 唐代專題包含作者小傳、時代背景、時間軸與活動地點互動地圖。 |
| 教師校對 | 可針對 AI 輔助語譯留下修改建議，並將資料以 JSON 格式匯出。 |

## 百篇資料狀態

目前 `client/src/data/classics100.json` 共有 100 篇、731 個段落。每個段落皆有原文與可用白話語譯；其中部分新補篇目標示為「來源補齊－待教師校對」，表示已整理來源與教學語譯，但仍建議由教師進行逐段核閱。網站不把尚未核對的內容標示為正式教材。

## 資料來源與編寫原則

篇目與部分教材結構參考臺北市教育局國語文學科中心的[古典名篇資料庫][1]及其教材頁。公開典籍原文亦參考[維基文庫][2]進行文字核對。網站中的白話語譯是為本專案重新整理的教學文字，不直接複製來源頁的語譯；實際使用時仍應以教師授課版本與正式教材為準。

## 本機啟動

本專案使用 React、TypeScript、Vite 與 Tailwind CSS。請先安裝 Node.js 與 pnpm，接著在專案根目錄執行：

```bash
pnpm install
pnpm dev
```

瀏覽器開啟 `http://localhost:3000/` 即可進入開發環境。正式建置與型別檢查指令如下：

```bash
pnpm check
pnpm build
```

## 專案結構

| 路徑 | 用途 |
| --- | --- |
| `client/src/pages/Home.tsx` | 首頁、篇章閱讀、檢索與學習互動。 |
| `client/src/data/classics100.json` | 百篇文白資料庫。 |
| `client/src/lib/catalog.ts` | 篇目索引、分類與朝代篩選資料。 |
| `client/src/lib/tangClassics.ts` | 唐代五篇深化教材資料。 |
| `client/src/lib/studyData.ts` | 測驗紀錄、錯題本與作者脈絡資料。 |
| `client/src/index.css` | 紙頁風格、標楷體閱讀字型與響應式樣式。 |

## GitHub Pages

本專案透過 GitHub Actions 建置 `dist/public`，並發布至 GitHub Pages。推送至 `main` 分支後，工作流程會自動執行型別檢查、正式建置與 Pages 發布。專案儲存庫的 Pages 網址格式為：

`https://qpooqp889.github.io/guowen-classics/`

本專案程式碼可作為教學與個人學習用途。古典文獻多屬公版資料，但不同教材版本的標點、分段與注釋可能有所差異；若用於課堂、出版或正式教材，請再次核對原始版本與版權／引用規範。
